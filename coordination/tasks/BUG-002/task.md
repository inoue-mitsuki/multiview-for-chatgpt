# タスク定義

- タスクID: BUG-002
- ステータス: 条件付き完了（Brave実機確認待ち）
- 背景: プロジェクト、スケジュールなどの左サイドバーナビゲーションで、親ページだけが変わり分割表示が残る。前回追加した戻るボタンはユーザーの希望に合わない。
- 目的: 戻るボタンを削除し、会話以外のChatGPTナビゲーションを画面1で開く。
- 要求: 会話通常クリックは従来通り画面1。プロジェクト、スケジュール、ライブラリ、プラグインなども画面1。三点リーダーの割当、画面2～4、プロフィール表示を維持。
- 完了条件: 実装・構文確認・独立レビュー後、Braveで実際のクリック動作を確認する。
- 対象ファイル: extension/content.js、extension/manifest.json、extension/README.md。
- 依存タスク: FEATURE-005、FEATURE-006。
- リスク: ChatGPT側でプロジェクトのホームがリンクではなくボタンとして実装されている場合、親ページのURL変化を検出して画面1へ反映する。ページ全体が再読み込みされる場合は分割UIが消えるため再検討が必要。
