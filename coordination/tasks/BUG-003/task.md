# タスク定義

- タスクID: BUG-003
- ステータス: 条件付き完了（0.8.0の静的検証済み、Brave実機確認待ち）
- 背景: 会話メニューの「画面1～4で開く」がプロフィールおよびアカウントメニューにも現れる。プロフィールは親ページで開き、分割表示と両立しない。
- 目的: 画面割当を個別会話の三点リーダーメニューだけに限定し、プロフィールを画面1で開く。
- 要求: プロフィール系メニューに画面割当項目を出さない。個別会話のメニューは維持。プロフィールを選択したら画面1で表示し、画面2～4は維持。外部URLを画面1に取り込まない。
- 完了条件: 静的確認、独立レビュー、Brave実機でプロフィールと会話メニューを確認。
- 対象ファイル: extension/content.js、extension/manifest.json、extension/README.md。
- リスク: ChatGPTが既存メニューDOMを再利用した場合の検出差、プロフィールページのiframe制限。0.8.0ではページ全体の遷移後にセッション状態から分割を復元する。
