# Multiview

ChatGPT専用。複数の会話を、同じタブ内で2〜4画面に並べて表示するブラウザ拡張機能です。

## はじめての使い方

1. Chrome ウェブストアからインストールし、下記「サイトへのアクセス」を設定してChatGPTへログインします。既にChatGPTを開いていた場合は、初回にページを一度再読み込みしてください。
2. ページ右上付近の、4つの四角が描かれた丸いボタンをクリックします。ボタンはドラッグで移動できます。
3. 「2」「3」「4」から画面数を選び、サブメニューで配置を選択します。
4. サイドバーの会話の「…」→「分割表示」→「画面○で開く」で表示先を選びます。空画面では「新しいチャット」から開始できます。
5. 終了は4マスボタンの「分割を終了」です。

メニューの「2・3・4」は画面数です。「画面1〜4」と会話行の丸い番号は、会話を表示している画面の番号です。通常表示は分割していない状態を指します。

ブラウザのツールバーにある拡張機能アイコンは、通常表示から4画面を開始し、分割中は終了する操作です。画面数や配置を選ぶには、ページ内の4マスボタンを使います。保存済みの復元情報がある場合は前回の状態を再利用します。

## 更新後の復旧

0.26.0以降は、インストール・更新時に開いているChatGPTタブの操作処理を自動で復旧することを試みます。サイトへの自動アクセス許可が必要です。復旧経路では分割の開始・終了を切り替えず、親ページや既存分割画面を再読み込みしない設計です。既存画面の入力もその場で維持する設計で、入力内容を保存する機能ではありません。

0.24.0で導入したホット復旧に対応する版同士では、ツールバーの拡張機能アイコンによる復旧も試みます。正常に応答する同じ版でのクリックは従来どおり分割の開始・終了です。

旧0.23.1には必要な引き継ぎ機能がありません。初回移行では入力を手元に退避してから、ChatGPTページを手動で再読み込みしてください。旧処理の停止完了を確認できない場合も、既存画面を保護し、復旧成功とは扱いません。0.26.0では許可ON後の更新・操作成功がユーザー確認されていますが、0.28.0での網羅的な実機確認と入力保持の検証は未実施です。

同じバージョンの拡張機能を再読み込みした場合も、ツールバーを押すと操作処理の応答を確認します。応答が途切れていた場合は復旧を試み、復旧したクリックでは分割を終了しません。正常に応答する場合は従来の開始・終了操作です。不正な応答や停止確認のない場合は画面を変更せず、手動移行が必要な状態として保護します。この追加対応は自動試験で確認しましたが、実ブラウザでの成功は未確認です。

## 保存と権限

### サイトへのアクセス

`chrome://extensions` または `brave://extensions` → Multiviewの「詳細」→「サイトへのアクセス」で、自動アクセスを許可し、`https://chatgpt.com/*` をONにしてください。表示名はブラウザによって異なります。OFFでは更新後の自動復旧を利用できません。手動クリックによる一時的な権限で一部の操作ができる場合はあります。

会話URL・画面数・配置・サイズなどの復元情報を、ブラウザ内の拡張機能用ローカルストレージとChatGPTページのsessionStorageに保存します。アイコン位置もsessionStorageに保存します。sessionStorageの情報はChatGPTと同じオリジンのページコードからもアクセスできます。会話本文や未送信入力は保存せず、独自サーバーへ情報を送信しません。

storageは復元情報の保存、activeTabとscriptingはChatGPTタブの分割操作・復旧、contextMenusは右クリックの画面選択・診断に使用します。`https://chatgpt.com/*` のホスト権限は、インストール・更新時に開いているChatGPTタブへの自動注入・復旧に使用します。分割画面内のChatGPTは通常どおりChatGPTサービスと通信します。

## 0.28.0の修正

狭いナビ項目とChatGPT見出しへの追加三点・番号の誤表示、三点の再クリック開閉、分割内のナビ予約幅による背景境界、Work項目への分割操作の誤付与を修正しました。本文の標準最大幅・中央寄せは維持しています。自動回帰13件は成功していますが、修正版の実ChatGPT・Braveでの確認は未実施です。
