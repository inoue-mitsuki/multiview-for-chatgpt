# Multiview

ChatGPT専用の分割表示拡張機能です。OpenAIの公式製品ではありません。

ChatGPTの標準サイドバーを左に1つ残し、右側に2、3、4画面を表示します。サイドバーの会話を通常クリックすると画面1で開き、会話行の三点リーダーからは画面1～4へ割り当てられます。プロジェクト、スケジュール、ライブラリ、プロフィールなども画面1で開きます。プロフィールやアカウントのメニューには画面割当項目を追加しません。開始時は画面1に現在のページ、ほかの画面に新しいチャットを表示します。

## 更新後のホット復旧

0.24.0のcontrollerは、対応hookを持つ版同士で、更新後のツールバーアイコン1クリックにより交代します。既存paneのiframe DOMと入力を維持し、親ページ・子iframeの再読み込みは行わない設計です。入力は保存領域へ永続化しません。同版の通常クリックは従来の開始・終了toggleを維持し、新権限は追加しません。

交代は前回のackを消去して同期通知し、旧処理のlistener・監視などのcleanup完了を示すackを確認した後、状態のschemaとhost構造を検証して既存画面を引き継ぎます。停止完了のackがない場合は、安全な未完了として扱い、既存paneを壊して通常開始へ切り替えません。旧0.23.1はhook非対応のため、初回移行は入力を手元へ退避してからChatGPTページを手動再読み込みしてください。実ChatGPTでの引き継ぎ・入力保持は未確認です。

## 開発版のインストール

1. Braveでは `brave://extensions`、Chromeでは `chrome://extensions` を開きます。
2. デベロッパーモードを有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」でこの `extension` フォルダーを選びます。既に読み込んでいる場合は丸い矢印で再読み込みします。
4. `https://chatgpt.com/` を開いてページを更新し、拡張アイコンを押します。

右上の2、3、4ボタンで画面数を切り替えます。境界はドラッグで調整できます。各画面の更新ボタンはその画面だけを読み直します。「分割を終了」または拡張アイコンで元のページへ戻れます。

分割中にプロフィールなどへページ全体が移動した場合は、同じタブのセッション状態から分割画面を再表示し、移動先を画面1で開きます。画面2～4のURLと画面数を引き継ぎます。画面3・4は表示されるまで読み込みません。境界の幅・高さは保存しません。「分割を終了」を押すと、この自動再表示も停止します。

まだ分割していなくても会話リンクの右クリックから表示先を選べます。画面3や4を選んだ場合は必要な画面数へ切り替えます。右クリックメニューが見えない場合は拡張の再読み込みとChatGPTページの更新を試してください。

会話の画面割当は通常会話URL（`https://chatgpt.com/c/...`）とプロジェクト内会話URL（`https://chatgpt.com/g/.../c/...`）を対象にします。拡張は会話内容を収集、保存、送信しません。ChatGPTのページ構造が変わると、標準サイドバーの位置検出や各画面内のサイドバー非表示が動かなくなる可能性があります。サイドバー検出に失敗した場合は左幅を260pxとして表示します。画面内の埋め込みをChatGPT側が拒否する場合もあります。

0.8.1では、会話の三点リーダーを押した際に会話自体が画面1へ移動してメニューが消える問題を修正しました。更新後は拡張機能を再読み込みし、ChatGPTのタブも更新してください。

プロジェクトなどの画面1への移動はBrave実機で確認が必要です。
