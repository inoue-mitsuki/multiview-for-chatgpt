# ChatGPT 分割ビュー（実験用）

0.22.0では前回の画面数・配置・幅と高さ・親タブと各画面のURL・空画面などの復元情報を、ブラウザ内の拡張機能用ローカルストレージとChatGPTページのsessionStorageへ保存します。アイコン位置もsessionStorageに保存します。sessionStorageの情報は、ChatGPTと同じオリジンのページコードからもアクセスできます。ブラウザを閉じた後も、ChatGPTを開くと前回表示していた全画面を自動読み込みします。隠れている画面は表示するまで読み込みません。「分割を終了」は自動開始を止め、次に手動開始すると前回の状態を再利用します。全画面自動復元は複数のページ読み込みを発生させます。入力途中の文章・会話本文・スクロール位置は保存しません。storage権限を使用し、独自サーバーへ保存内容を送信しません。

0.21.0では、同じ会話や標準ページを別画面へ割り当てると、元の画面を空にします。通常URLとプロジェクト内URLの同じ会話は会話IDで照合します。スケジュール・ライブラリ・プラグインも一つの画面にだけ表示し、番号は移動先へ移ります。新しいチャットは複数画面で独立して使えます。

ChatGPTの標準サイドバーを左に1つ残し、右側に2、3、4画面を表示します。サイドバーの未表示の会話を通常クリックすると画面1で開きます。すでに画面1～4で表示中の会話は通常クリックしても移動しません。画面数を減らして隠れた画面の会話も、通常クリックでは画面数を変えません。その会話を表示するには画面数ボタンを選びます。表示先を変える場合は会話行の三点リーダーにある「分割表示」へポインターを乗せるかフォーカスすると、右側に「画面1～4で開く」が表示されます。「プロジェクトに移動」の中には追加しません。プロジェクト、スケジュール、ライブラリ、プロフィールなども画面1で開きます。プロフィールやアカウントのメニューには画面割当項目を追加しません。開始時は画面1に現在のページを表示し、未使用の画面2～4には案内と「新しいチャット」ボタンを表示します。ボタンを押した画面だけChatGPTを読み込みます。開いている会話は標準サイドバーで左端に画面番号を表示し、行を薄い青で示します。

## はじめて使う方へ

1. Chrome ウェブストアからインストールし、ChatGPTへログインします。インストール前から開いていたChatGPTタブは一度再読み込みしてください。
2. ChatGPTページ右上付近の「4つの四角」が描かれた丸いボタンをクリックします。ボタンはドラッグで移動できます。
3. メニューの「2」「3」「4」から画面数を選び、サブメニューで配置を選択します。
4. 左サイドバーの会話の「…」→「分割表示」→「画面○で開く」で、会話の表示先を選びます。空画面では「新しいチャット」から開始できます。
5. 終了するには、4マスボタンの「分割を終了」を選びます。

メニューの「2・3・4」は表示する画面数です。「画面1〜4」とサイドバーの丸い番号は、会話を表示している画面の番号です。通常表示は分割していない状態で、「画面1」とは異なります。

ブラウザのツールバーにある拡張機能アイコンは、通常表示から押すと4画面を開始し、分割中に押すと終了します。画面数や配置を選ぶ場合は、ChatGPTページ内の4マスボタンを使用してください。復元情報がある場合は前回の会話や配置を再利用します。

## 開発版のインストール

開発後の回帰確認は `tests/REGRESSION.md`、一括自動確認は `tests/run-tests.ps1`、結果記録は `tests/RESULT-TEMPLATE.md` を使用します。自動試験とBrave実機確認は別に記録します。

1. Braveでは `brave://extensions`、Chromeでは `chrome://extensions` を開きます。
2. デベロッパーモードを有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」でこの `extension` フォルダーを選びます。既に読み込んでいる場合は丸い矢印で再読み込みします。
4. `https://chatgpt.com/` を開いてページを更新し、拡張アイコンを押します。

通常画面でも分割中でも丸い4マスボタンを表示します。ボタンをクリックして開くメニューから2・3・4画面の開始・切替、分割終了を操作します。同じメニューの「3画面の設定」へポインターを乗せるかフォーカスし、サブメニューで「横3列」または「左大＋右上下」を選ぶと、その配置の3画面に切り替わります。選択は同じタブの再読み込み後も維持されます。上部の画面数バーはありません。ボタンはドラッグで移動でき、同じタブの再読み込み後も位置を維持します。分割中は各画面の左上に「画面2｜スクワット記録」のように会話名を表示します。長い会話名は画面幅に合わせて省略し、サイドバーから名前を取得できないときは画面番号のみ表示します。境界はドラッグで調整できます。各画面の更新ボタンはその画面だけを読み直します。右側の「×」はその画面だけを空にして案内へ戻します。更新ボタンは「×」の左側にあります。会話履歴と他の画面はそのままです。空にした画面の未送信入力は失われる場合があります。

ページ全体を再読み込みしても、前回の分割画面と境界の幅・高さを復元します。起動時の親ページURLで画面1を上書きしません。未使用の空画面はChatGPTを読み込みません。保存内容が破損している場合は自動開始せず、通常表示から利用できます。

まだ分割していなくても会話リンクの右クリックから表示先を選べます。画面3や4を選んだ場合は必要な画面数へ切り替えます。右クリックメニューが見えない場合は拡張の再読み込みとChatGPTページの更新を試してください。

会話の画面割当は通常会話URL（`https://chatgpt.com/c/...`）とプロジェクト内会話URL（`https://chatgpt.com/g/.../c/...`）を対象にします。拡張は会話内容を収集、保存、送信しません。ChatGPTのページ構造が変わると、標準サイドバーの位置検出や各画面内のサイドバー非表示が動かなくなる可能性があります。サイドバー検出に失敗した場合は左幅を260pxとして表示します。画面内の埋め込みをChatGPT側が拒否する場合もあります。
